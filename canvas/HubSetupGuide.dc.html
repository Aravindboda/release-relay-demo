Create the hub certificateSalesforce admin

Setup → Certificate and Key Management → Create Self-Signed Certificate

Why: The hub signs its logins to every org with this certificate. No passwords are stored.

  1. Label: release_relay.
  2. Unique Name: release_relay (exactly this, lower case).
  3. Tick Exportable Private Key (the pipeline needs the key too).
  4. Key Size: 2048.
  5. Press Save.

✓ What you should see: The certificate page shows release_relay with Exportable Private Key: Yes.

Promote tab

Why: One block per stage: the releases deployed there and not promoted yet.

  1. Tick the releases to promote. Hotfixes first; a hotfix can go on its own.
  2. The right panel counts releases and components and lists the tests that run.
  3. Give the promotion a Title.
  4. Press Promote 3 releases to PROD.

✓ What you should see: A Promotion release on promote/rel-xxxxx runs the scan, check-only deploy and tests.

Promote: tick the releases, check the tests, title, Promote.
